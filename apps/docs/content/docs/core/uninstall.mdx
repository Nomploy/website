title: Uninstall
description: "Learn how to uninstall Nomploy on your server"
---

import { Step, Steps } from 'fumadocs-ui/components/steps';

Follow these steps to completely remove Nomploy and its components from your server.

<Steps>
<Step>
Remove the docker swarm services created by Nomploy:

   ```bash
   docker service remove nomploy nomploy-traefik nomploy-postgres nomploy-redis
   docker container remove -f nomploy-traefik
   ```
 
</Step>
 
<Step>
 
Remove the docker volumes created by Nomploy:

   ```bash
   docker volume remove -f nomploy nomploy-postgres nomploy-redis
   ```
 
</Step>

<Step>
 
Remove the docker network created by Nomploy:

   ```bash
   docker network remove -f nomploy-network
   docker network remove -f ingress
   ```
 
</Step>

<Step>

If you were running a Cluster, then for each worker node, remove all it's services and make it leave the swarm:

   ```bash
   docker service rm $(docker service ls -q)
   docker system prune -a -f
   docker swarm leave
   ```
</Step>

<Step>

Make the manager node (where Nomploy is installed) leave the swarm (run it on all manager nodes if you had more than one):

   ```bash
   docker swarm leave --force
   ```
</Step>

<Step>

Docker cleanup to remove leftovers:

   ```bash
   docker container prune --force
   docker image prune --all --force
   docker volume prune --all --force
   docker builder prune --all --force
   docker system prune --all --volumes --force
   ```
 
</Step>
 
<Step>

Remove the nomploy files and directories from your server:

   ```bash
   sudo rm -rf /etc/nomploy
   ```
 
</Step>
</Steps>
