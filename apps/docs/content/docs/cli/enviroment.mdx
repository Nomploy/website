The Nomploy CLI can be used to create, deploy, and manage enviroments.

## Requirements

Is required to be already authenticated with the Nomploy CLI.


## Commands

1. `nomploy env pull <file>` -  Pull environment variables from Nomploy in a file.
2. `nomploy env push <file>` - Push environment variables to Nomploy from a file.
