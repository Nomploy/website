description: A guide to using the Nomploy command-line interface
---

Nomploy CLI is a command-line tool for remotely managing your Nomploy server. It simplifies creating, deploying, and managing applications and databases.

## Installation

```bash
npm install -g @nomploy/cli
```

## Usage

```bash
nomploy COMMAND
```
To get help on a specific command:

```bash
nomploy COMMAND --help
```
