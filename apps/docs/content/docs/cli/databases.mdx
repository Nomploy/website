The Nomploy CLI can be used to create, deploy, and manage databases.

## Requirements

Is required to be already authenticated with the Nomploy CLI.


## Commands

### MariaDB 

1. `nomploy database mariadb create` - Create a new mariadb database.
2. `nomploy database mariadb delete` - Delete an mariadb database.
3. `nomploy database mariadb deploy` - Deploy a mariadb database.
4. `nomploy database mariadb stop` - Stop a running mariadb database.
