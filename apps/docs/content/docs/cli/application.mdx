The Nomploy CLI can be used to create, deploy, and manage applications.

## Requirements

Is required to be already authenticated with the Nomploy CLI.


## Commands

1. `nomploy app create` - Create a new application.
2. `nomploy app delete` - Delete an application.
3. `nomploy app deploy` - Deploy an application.
4. `nomploy app stop` - Stop a running application.
